agent-think-map is a visual debugger for captured agent events. This hosted page is a canvas sample, not hosted Studio history, Problems or Compare; those run locally. No upload, account, backend or telemetry. No automatic diagnosis or chain-of-thought guarantee.

Requires Node >=22.13.0. Choose your coding agent:

Claude Code

npx agent-think-map@latest claude --install

Run from the project, keep Studio running, and restart Claude if it is open.

Codex

npx agent-think-map@latest codex --install

Keep Studio running, restart Codex, and honor its existing consent prompt.

These install commands add capture hooks. Read the setup details and consent conditions before connecting your agent.

Hook-free history import · Claude only

npx agent-think-map@latest claude --import-history --dry-run
npx agent-think-map@latest claude --import-history

Import exits without opening Studio. Then start Studio without changing hooks:

npx agent-think-map@latest claude

See history import details and limits.
